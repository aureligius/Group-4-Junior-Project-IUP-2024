# CARBON KICKERS
# Group-4-Junior-Project-IUP-2024
a gamified web application that transforms personal carbon footprint reduction into a competitive, engaging experience. Instead of just tracking emissions CARBON-KICKERS turns sustainibility into a sport. Users log their daily activities, such as transportation and destination choices to calculate their real-time carbon footprint.
