## Project Description
CARBON-KICKERS is a gamified web application that transforms personal carbon footprint reduction into a competitive, engaging experience. Instead of just tracking emissions CARBON-KICKERS turns sustainibility into a sport. Users log their daily activities, such as transportation and destination choices to calculate their real-time carbon footprint. 
 
## Core Features  
1. The Arena (PvP Battles): Users can challenge friends or join weekly community leagues to compete for the lowest carbon footprint. 

2. Smart logging: Integrates with APIs (Like Google Maps for transport distance and Climatiq for emission factors) to accurately calculate CO2 savings 

3. Progression System: Users earn "Green XP" and unlock badges, climb league tiers (Bronze to Diamond), and earn virtual rewards for consistent eco-friendly habits. 

4. Trip Tracking: Detect or record when the user starts and ends a trip + calculate the distance traveled. 

5. Carbon Emission Calculation: Calculate the estimated CO₂ emissions for each trip 

6. Impact Dashboard: Visualizes the user's historical data, showing exactly how much CO2 they have "kicked" out of the atmosphere over time
